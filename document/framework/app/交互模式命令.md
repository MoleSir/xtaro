# 交互模式命令

## 配置信息

- `config <xxx.json>`：加载配置文件



## 编译

- `compile`：编译生成内存中的 SRAM 对象
- `reset`：清除 SRAM 对象



## 保存文件

- `write [--spice] [--verilog] [--liberty]`：输出 spice、verilog 与 liberty 文件
- `write_spice`：输出 spice 文件
- `write_verilog`：输出 verilog 文件
- `write_liberty`：输出 liberty 文件



## 仿真

- `function <process> <voltage> <temperature> <slew> <load>` ：在指定 PVT 以及输入 slew、输出负载 load 的情况下，对 SRAM 进行功能测试
- `delay <process> <voltage> <temperature> <slew> <load>`：在指定 PVT 以及输入 slew、输出负载 load 的情况下，计算 SRAM 延时信息
- `setuphold <process> <voltage> <temperature> <slew> <slew>`：在指定 PVT 以及输入 slew、输出 slew 的情况下，计算 SRAM 的建立、保持时间



## 电路测试

- `create <circuit_type> [arg_name=arg_value] [-o output_file_name]`：输出指定类型、参数的电路 SPICE 网表
- `test <config_file>`：根据 config_file 信息，输出对指定电路的测试激励。config_file 为 .json 格式文件。



## 其他

- `exit`：退出
- `clear`：清屏
- `help [command_name]` ：显示指定命令的帮助信息
- `logo [color]`：显示指定颜色的 logo
